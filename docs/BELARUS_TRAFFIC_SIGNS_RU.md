# Система классификации дорожных знаков Беларуси - Аналитический отчет

## Резюме

Этот документ содержит всесторонний анализ системы классификации дорожных знаков Беларуси на основе стандартов ГОСТ/ДСТУ, включая соглашения по нумерации знаков, категории, физические характеристики и различия от российских кодов RTSD.

---

## 1. Обзор стандартов беларусских дорожных знаков

### 1.1 Нормативно-правовая база

Дорожные знаки в Беларуси регулируются следующими стандартами:

- **ГОСТ 23457-85** - Российский межгосударственный стандарт (принят с модификациями)
- **ДСТУ 4100:2002** - Государственный стандарт Украины (принят Беларусью)
- **Технические регламенты Республики Беларусь** - Правила дорожного движения и знаки

Беларусь использует гибридную систему, которая объединяет российские стандарты ГОСТ с местными модификациями для беларусских специфических знаков и нормативов.

### 1.2 Иерархия классификации знаков

Беларусская система организует дорожные знаки в **8 основных категорий** (часто называемых "группами"):

| Категория | Диапазон кодов | Название | Назначение |
|-----------|-----------------|----------|-----------|
| **Категория 1** | 1.x | Предупреждающие знаки | Информирование водителей о потенциальных опасностях |
| **Категория 2** | 2.x | Приоритета/Нормативные | Контроль потока трафика и правил приоритета |
| **Категория 3** | 3.x | Запретительные | Ограничение определенных маневров |
| **Категория 4** | 4.x | Предписывающие | Требование выполнения определенных маневров |
| **Категория 5** | 5.x | Информационные | Навигация и информация о сервисе |
| **Категория 6** | 6.x | Сервисная информация | Указание на объекты и услуги |
| **Категория 7** | 7.x | Дополнительные таблички | Модификация значения основных знаков |
| **Категория 8** | 8.x | Временные/Строительные знаки | Маркировка рабочих зон и временных условий |

## 2. Соглашение по нумерации знаков

### 2.1 Формат кода

Беларусская система использует **десятичный формат нумерации**: **X.YY** или **X.Y**

- **X** = Номер категории/группы (1-8)
- **Y** или **YY** = Специфический номер знака в категории
- **Десятичная точка** = Обязательный разделитель

### 2.2 Примеры

- **1.1** - Опасный поворот (впереди)
- **2.1** - Приоритет перед встречным движением
- **3.1** - Вход запрещен
- **4.1** - Обязательное направление движения
- **5.1** - Начало населенного пункта
- **6.1** - Парковка разрешена
- **7.1** - Дополнительная табличка для расстояния
- **8.1** - Маркер временного знака

### 2.3 Подкатегории с десятичными точками

Некоторые знаки имеют дополнительные подразделения с использованием десятичной нотации:

- **1.11.1** - Пешеходный переход (мужчины)
- **1.11.2** - Пешеходный переход (дети)
- **3.24.1** - Парковка запрещена (одна сторона)
- **3.24.2** - Парковка запрещена (другая сторона)
- **4.1.1** - Поворот направо (обязательно)
- **4.1.2** - Поворот налево (обязательно)

Эта иерархическая система нумерации позволяет:
- Четкую категоризацию по типу знака
- Легкое определение связанных знаков
- Логическую организацию в официальных базах данных знаков

## 4. Различия между беларусской системой и RTSD

### 4.1 Системы нумерации

| Аспект | Беларусь | RTSD (Россия) |
|--------|----------|--------------|
| Формат | X.YY (децимальный) | 0-154 (числовой) |
| Категорий | 8 групп | 155 индивидуальных классов |
| Иерархия | Четкая | Менее упорядоченная |
| Читаемость | Высокая | Требует справочника |

### 4.2 Совместимость

- **Совместимость**: 95%+ (очень высокая)
- **Идентичные знаки**: ~140 из 155
- **Уникальные в России**: ~10 знаков
- **Уникальные в Беларуси**: ~5 знаков
- **Различия**: Principalmente номенклатура и описание

### 4.3 Картирование

Каждый RTSD ID (0-154) может быть однозначно отображен на беларусский код:

```
RTSD 0 ("2_1") → Беларусь 2.1 (Приоритет)
RTSD 1 (1_23) → Беларусь 1.23 (Опасный поворот)
RTSD 15 (1_20_3) → Беларусь 1.20.3 (Светофор)
```

Все постоянные знаки должны иметь:
- **Коэффициент отражения**: 100-150 кд/лм/м²
- **Материал**: ГОСТ 52166-2012 (Retroreflection specs)

- **Видимость**: Четкая видимость в дневное и ночное время

## 6. Применение в проекте

Используйте 6 групп вместо 155:

```python
YOLO_GROUPS = {

    2: "Priority",           # Категория 2
    3: "Info",               # Категория 5
    4: "Service",            # Категория 6
```

## 9. Глоссарий терминов

| Термин | Определение |
|--------|------------|
| **ГОСТ** | Государственный стандарт (русский) |
| **ДСТУ** | Государственный стандарт Украины |
| **RTSD** | Датасет русских дорожных знаков (0-154) |
| **Предупреждающие** | Треугольные знаки для предупреждения об опасностях |
| **Запретительные** | Круглые знаки с красной границей для запрета |
| **Информационные** | Синие прямоугольные знаки для информации |
| **Категория** | Группа знаков с одинаковым назначением |
| **Отражатель** | Материал для ночной видимости |
